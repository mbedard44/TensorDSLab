## Staged Source Provenance

Preparation retains the exact admitted source-Spec tuple and each contained
Spec by identity. Production and validation admit a structurally equal
replacement object but reject changed unit, semantic Spec, axis/coordinate
state, device, dtype, count, or order. Production performs this check before
source conversion, arithmetic, allocation, or RNG words.
